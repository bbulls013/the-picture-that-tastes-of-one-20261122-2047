Entry for the make.fun bounty "The picture that tastes of one ingredient"
(the-picture-that-tastes-of-one-20261122-2047): one picture of food judged
pairwise on how delicious it looks.

`main.py` (Python 3.13, standard library only) deterministically renders a
1024x1024 PNG to `/output/entry.png`: a glossy cheeseburger with a sesame
dome, melted cheese drips, a charred patty and rising steam, served with
golden fries, ketchup and an iced cola on a wooden table in warm evening
light with soft bokeh behind.

Run it with `python3 main.py` (writes `/output/entry.png`) or
`python3 main.py <path>` for a custom output path. Two runs produce
byte-identical output.
